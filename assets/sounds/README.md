# Muestras de batería

Estos cuatro archivos WAV proceden de las muestras CC0 de [Virtuosity Drums](https://github.com/sfzinstruments/virtuosity_drums), distribuidas en los paquetes [ferrosintesis-samples-drumkit 0.2.0](https://crates.io/crates/ferrosintesis-samples-drumkit/0.2.0) y [ferrosintesis-samples-drumkit2 0.2.0](https://crates.io/crates/ferrosintesis-samples-drumkit2/0.2.0). Se convirtieron de FLAC a WAV PCM de 16 bits y 44,1 kHz sin cambiar el contenido musical. La licencia se incluye en `LICENSE-CC0`.

| --- | --- |
| `kick.wav` | `kick_vl4_rr1.flac` (drumkit) |
| `snare.wav` | `snare_vl4_rr1.flac` (drumkit) |
| `hihat.wav` | `hhc_vl4_rr1.flac` (drumkit) |
| `splash.wav` | `splash_vl1_rr1.flac` (drumkit2) |
